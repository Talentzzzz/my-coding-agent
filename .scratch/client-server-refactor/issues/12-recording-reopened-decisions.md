## Answer

**2026-10-12 解决。本票是本次重开里唯一落了盘的票：它落的不是代码，是记录层。** 代码一行未动，`docs/architecture.md` 的正文也一行未动——交付物是 `docs/adr/0001-transport-websocket-mux.md`（外加 `docs/adr/README.md` 这份目录索引：门槛、编号规则、写法）、`docs/notes.md` 第一节的就地标注，以及两处索引里"`docs/adr/` 尚不存在"这句已经变假的陈述。

**读下面的行号时注意**：本票自己把 `docs/notes.md`、`docs/README.md` 改长了几行，所以上面 `## Question` 里的行号引用是**提问当时**的快照，不是现在的（例如它引的 `docs/README.md:44` 现在是"还没有的文件"那一节）。下面 Answer 里的引用一律是改完之后的。

### 1. 写在哪：三个地方，三种职责，不重复

| 文件 | 只回答 | 不回答 |
|---|---|---|
| `docs/adr/0001-*.md` | **为什么改主意**——背景、被推翻的原决定、没被推翻的边界、代价与不可逆性 | 实况（那是 `architecture.md`）、结论清单（那是 `notes.md`） |
| `docs/notes.md` 第一节 | **哪些结论作废**——原文保留、当场划线、标注取代者 | 理由。本票在节首与节尾都写了同一句："理由在 ADR-0001 或它引的票里" |
| `docs/architecture.md` + `AGENTS.md` 的 `## 术语` | **现在的实况与现在的词义** | 历史。本票**未动**这两处，理由见决定 4 |

`CONTEXT.md` **本票不创建**。它是术语表，而术语今天没有出现"不写下来就会用错词"的歧义；`docs/agents/domain.md:45` 说得很清楚——在它出现之前以 `AGENTS.md` 的术语章节为准。**ADR 则相反：它现在真的需要了**，因为"不得重开"这层保护已经用掉一次，而 `notes.md` 只记结论不记理由，只靠它就会让下一次重开看起来像漂移。这也正是 `docs/README.md` 的"还没有的文件"那一节说的惰性创建：等决定真正被敲定时才写。

### 2. `docs/notes.md` 那一节：保留原文 + 就地标注，标题跟着改

**不删条目、不重写正文**，每条作废的结论就地划掉并注明取代者。理由是诚实：节首那段"它们看起来可以改得更好，而每一次都已经被否决过"正是本次重开的**对象**，删掉它就没人看得出这里发生过一次逐个称过的推翻。

**标题改成「重开过的，与不得重开的决定」**，因为旧标题"与用户共同作出、**不得重开**的决定"在重开之后是**假的**。改标题不是措辞洁癖：那一节现在同时装着两类条目（被重开的与仍然有效的），标题必须能同时覆盖它们，否则下一个人要么以为整节都作废、要么以为整节都还在生效——两种误读都有代价。

逐条落地的标注（与 ADR 的对照表一一对应）：

- 「传输形态不变」整节 → **被 ADR-0001 取代**（三条全划掉）。它恰好是被并成一条写的两半，所以标题也改成了「传输形态不变 **—— 被 ADR-0001 取代**」。
- 「不做序列号、游标、重放缓冲或缺口修复」→ **保留**，并补了常驻通道下的读法（基线 + 增量之间没有缺口）。
- 「`claim` 保留原义」→ **保留，但有一条失效**：只划掉"每条事件流一个 claim"，重命名禁令与"订阅不拿 claim"（后来在这条之上定的）原样有效。
- `packages/ai`/`agent` 一行不改、测试不需要密钥、不要顺手修 `smoke-approval.ts` → **保留**。
- D0 → **取代**（流随订阅者存活）；D2 → **取代**（终帧改叫 `end`——它是两个名字之间的一次选择，且继任者有名有姓，所以是取代而不是失效；这一处是评审查出后改正的，原稿沿用了地图的"失效"）；D3 → **取代**；D1 → **保留**。
- §二 加了一段读法：第 1–3 条讲的是 `EventSource` 的机制（随传输切换退场），**没有一条被删掉**，事实仍然有效，但别当"当前客户端行为"读；第 4–8 条与传输无关。
- §六 加了一段：那节整节讲的正是本次在做的事；第三条（"多路复用流能买到的唯一东西……留在范围之外"）**已被推翻**，前两条仍是**当时**的对照。

### 3. 门槛：**一条** ADR，不是两条

按 `docs/agents/domain.md` 引的惯例（难以逆转 + 没有上下文会让人困惑 + 是一次真实取舍的结果），本次重开里只有传输这一条过门槛，**而且它本来就是同一个决定的两半**——"换协议"与"合流"描述的是同一条常驻连接。原判断里的两条（多路复用、不要 WebSocket）已在 2026-10-12 并成一条，本票把这条判定落成 ADR 正文里的一小节（*不是"不要 WebSocket"，是"多路复用不值得"*），并写明**为什么**是一个而不是两个。三点成文的东西收进 `docs/adr/README.md`：门槛、编号规则（只增不改，改写过的决定新开一条）、写法。

其余各条不够格：D0/D2/D3 **既是后果也是重新做过的决定**，所以它们在 ADR 的*被取代的是什么*那张表里按"取代"标注（不是只列进*这条决定已经长出了什么*那张）；`claim` 原义与"不做游标"是**边界**，列成"没有被取代的"一节。它们没有自己的 ADR，也不需要——它们各自都没有"另一次真实取舍"可言。

一条 ADR 只记**已定**的东西：`ws` 依赖还是手写 RFC6455 在 ADR 里明写"**尚未决定**"，浏览器 WS 的平台事实明写"**未确认**，在 `research/ws-multiplex.md` 落地之前一切按未确认对待"，并说清哪些判定**不依赖**这些取值（只有参数依赖）。

### 4. §3/§4 点名的正文：本票只登记落点，不提前改

**这是本票唯一一个与票面字面不同的决定，且是用户拍板的。** 理由：05–11 只产出决定，代码一行未动，树上跑的还是每会话一条 SSE；此时把 `architecture.md` 的 ASCII 图、`## wire`、`## API`、`## 谁拥有一个会话` 改成 mux 模型，就等于让设计参考描述一个不存在的系统，而落地票还要再改一遍同样的段落。

所以 ADR 里多了一节「落地清单」，把这些落点连同**归属**一起钉住：

- **代码落点**（`protocol.ts`、`session-manager.ts`、新的 `projection.ts`、`hub.ts`、`boot.ts`、`controllers/sessions.ts`、要整条删除的 `http/event-stream.ts`、新的 mux 连接层、`web/main.ts`、`web/render/sidebar.ts`、`web/state.ts` 今天没有读者的 `ViewState.sessions`、四个冒烟脚本、`desktop/main.cjs` 的 `before-quit`）；
- **文档落点**（`AGENTS.md` 的 `transport` 与 `claim` —— 两句今天**都不为真**；`AGENTS.md` 那条"加一个端点 = 控制器上一个方法 + `createRoutes()` 里一条记录"要补一句"**上行帧不是端点**"，因为 mux 的上行帧不走 URL、`Router` 仍是唯一解释 URL 的地方——本票判定它**不构成**对那条形状的破坏；`architecture.md` 的开头图与四节；`notes.md` §二/§六 的逐条重读；`README.md` 的*验证一次构建*与*状态*；`docs/README.md` 的指路行）；
- **两处已知漂移的处置**：`ServerMessage` 代码块缺 `stream_end`、以及 `:263` 那句"一条泄漏的流就是一台关不掉的服务器"（结论成立、机制描述不准确，正确说法是"只要有一条响应没结束，`server.close()` 的 `'close'` 回调就不发生"，出口是 `server.closeAllConnections()`；新模型下还要补写侧的另一半——一条常驻连接是一个 `Writable`，对端不读时"继续写"是无界缓冲）。两处都**随上面那次重写一起改**，本票不动 `architecture.md`。

**诚实限度**：在这批落点完成之前，`AGENTS.md` 的 `transport`/`claim` 与 `architecture.md` 的那四节**仍然描述着今天的代码**（这是对的），而 `notes.md` 第一节已经标了作废（这也是对的）。也就是说"实况"与"结论"之间会有一段有意的时差，两边都指得出对方是谁。
