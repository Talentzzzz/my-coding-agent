规则照用户原话：默认 5 条；点表头收起全部、只留表头；那 5 条底部「展开其余 N 个会话」，点一次 +5。

**三处没定的做成页面顶部控制台里的可翻开关**，让用户点着感受而不是读文字选：

1. **问题一 · 从收起点表头回到哪儿**：「前 5 条」/「上次那一页」（翻到「上次那一页」时，收起前的页码被记在 `savedPage` 里，展开时恢复）。
2. **问题二 · 全部展开之后按钮变成什么**：「消失」/「变『收起』」/「变『收起其余』」（后两者点了都回到 5 条，且**不动 `savedPage`**——问题一翻到「上次那一页」时，之后收起表头再展开仍回到收起前的页；按钮只在会话数超过 5 的工作区出现，没展开过的工作区不穿它）。
3. **问题三 · 收起状态记不记得**：「记住（跟 appearance）」/「不记（关窗即忘）」——页面提供**「重开窗口」**按钮来试：记住时重开原样，不记时全部回到 5 条、未收起。**没有用 localStorage**（桌面外壳每次启动换端口，origin 一变它就死，这是 04 号的刻意分歧）。原型里的「记住」是**内存态模拟**；appearance 真实的序列化→恢复那条路要等落地时才验得到，落地票要带上这一验。

已具备落地要的形态细节：表头是真按钮、带 `[aria-expanded]`，收起时 chevron 常显并转向右（不再只靠 hover 才知道那里可点）；活跃会话永远在场；「当前」标记与收起态共存。

**验证**：冒烟 20 项全过（初始 5 条、+5 翻页、≤5 条的工作区不穿按钮、三种问题二变体、两种问题一变体、收起只剩表头、`aria-expanded`、Q3 两种下的「重开窗口」）。

**注意（落地 task 票要带上）**：① `main.ts:708` 的重画签名 `${rows.version}|…|${collapsed ? 1 : 0}|${channel}` 要把**收展状态**带上，否则收起/展开根本不会重画；② `pickedWorkspace`（`main.ts:81`）驱动的「当前」标记要与收起态共存；③ 展开计数照真实现**按会话走**（根 + 它的派生算一个，见 `collapsedRows()`），原型为看得清按行数演示；④ 状态跟 `appearance` 走，不用 localStorage。

## Question

用户纠正了我"两态开关"的建议，要的是**分页 + 表头收起**（原话）：

> 一个工作区一开始只显示 5 个最近的会话，当用户点击工作区那一栏，就收起全部，只留一个工作区那一栏，
> 并且这 5 个底部有一个「展开其余会话」，点一下就再展开 5 个，直到都展示完。

**今天是半个机制，而且是单向的**（`packages/web/src/render/sidebar.ts`）：

- `COLLAPSED_COUNT = 4`（`:772`）——默认只有 **4** 条，不是用户说的 5；
- `collapsedRows`（`:658-670`）截断，底部那个「more」按钮（`:566-572`）只做一件事：
  `this.expanded.add(cwd)`——**`expanded` 从不删除，没有任何办法重新收起来**；
- 那个 Set 是**实例内的**：`ViewState`（`state.ts:197-229`）与 `AppearanceSettings`
  （`config.ts:42-67`，只有 theme / fontSize / sidebarWidth / contentWidth）里都**没有**它，关窗即忘；
- **表头根本没有接事件**：`div.workspace-head`（`sidebar.ts:318-359`）上 click / pointerdown / keydown
  **一个监听都没有**，连焦点都不可达；
- 而 CSS 里那个 hover 时把文件夹换成 chevron 的动效（`style.css:429-437`）**早就在假装那里可以点**
  ——一个**从没接线的承诺**，而且没有任何 `[aria-expanded]` / 旋转态可供挂靠；
- 参考实现**是双向**的（`.scratch/window-rework/research/ui-spec.md:120`：「展开其余 {n} 个会话」展开
  后变「收起」）。

**没定的三处**——原型要把它们摆出来让用户看，别在文字里猜：

1. **表头点一下回到哪儿**：从"收起"再点，是回到"5 条"，还是回到**上次展开到的那一页**？
2. **全部展开之后那个按钮变成什么**：消失、变成「收起」，还是「收起其余」？
3. **收起的状态记不记得**：记的话跟 `appearance` 走。**不能用 localStorage**——桌面外壳每次启动挑新
   端口，origin 一变 localStorage 就死；这是 04 号对参考实现的**刻意分歧**。

原型照惯例自包含、可双击打开、浅深两套、放进 `prototype/`，**照真窗口的构图做**（左栏 34px 表头 +
32px 行、meta/caption 档），这样用户读的是真读感。形态定了之后落地归一张 `task` 票。

**注意**：落地时左栏的重画门控要跟着改——`main.ts:708` 的签名字符串
`${rows.version}|${followed ?? ""}|${directory}|${pickedWorkspace}|${collapsed ? 1 : 0}|${channel}`
里**没有**收展状态的话，收起/展开**根本不会重画**。还有 `pickedWorkspace`（`main.ts:81`）驱动的
「当前」标记（`sidebar.ts:347-352`）要与收起态共存。

## Answer

**2026-10-16 用户在原型上当场拍板**（控制台里翻的开关，不是读文字选的）：

1. **问题一 · 从收起点表头 → 「上次那一页」**：不是屏上默认的「前 5 条」——用户翻到了「上次那一页」。收起前的页码记在 `savedPage` 里，展开时恢复。
2. **问题二 · 全部展开之后 → 变「收起」**（参考实现的原词）。点了回到 5 条、不动 `savedPage`，且只在会话数超过 5 的工作区出现。
3. **问题三 · 收起状态 → 记住，跟 appearance 走**。不用 localStorage（04 号的刻意分歧）。

原型（`prototype/09-workspace-paging.html`）的默认开关已改成这组拍板值，开关保留供回看。
