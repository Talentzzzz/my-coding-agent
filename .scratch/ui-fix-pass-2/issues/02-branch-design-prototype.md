# 02 · 分支页卡片与助手底部分支入口（原型）

Type: prototype
Status: resolved
Blocked by:

## Question

用户已经拍了两件事：分支**从助手回答发起**，最底部的助手消息不给按钮，从倒数第二条助手消息向上都给；
分支图在画布里**水平 + 垂直居中**。剩下的设计问题用原型回答，因为它在纸上说不清：

1. **一张分支卡写什么？** 用户对 Q3 的原话是「分支的哪条助手消息的上一条 user 消息」。它可能是
   A（卡片写助手回答）、B（提问 + 回答两行）、C（卡片写提问、回答进 tooltip）。三种都要能看见、
   能在真实密度下比较。
2. 卡片行数/高度变了之后，树还读得懂吗？图居中以后两条走法是否还平衡？
3. fork 图标在助手脚注里的位置（复制按钮右侧），以及「最底部那条没有」这条规则，是否一眼能看出来？

原型放在 `prototype/10-branch-pass.html`，用上一轮 `07-titlebar.html` 的窗口壳（真实侧栏、真实
标题栏、真实密度），`?variant=A|B|C` 切卡片、`?pane=chat|branch` 切页面，浮动条切方案。同一页里
固定展示：侧栏当前工作区的纯填充、助手脚注里的 fork、分支图居中。

## Prototype

- 文件：[prototype/10-branch-pass.html](../../../prototype/10-branch-pass.html)，`npm run prototype:branch`
  直接用桌面壳打开（`?pane=branch`）。
- 截图：`prototype/shot-branch-chat.png`（对话页 + fork 位置与规则）、`shot-branch-A.png`、
  `shot-branch-B.png`、`shot-branch-C.png`。
- 场景用用户自己的分支（会话 `2026-10-17T06-10-42…`）：分叉在「帮我看一下都有哪些文档」的回答上，
  当前走法是「你好」，另一条是「把这些文档摘成一张表」。
- 三种卡片的差别只在**一张卡写什么**；图居中、fork 位置、侧栏填充三件事在三种方案里都一样。

## Answer

用户看过原型后选了 **C · 提问卡**：卡片写提问，回答进 `title`，卡片仍是 48px 一代的高度（原型里 A 与 C
同高，B 才加高）；图在画布里水平 + 垂直居中这条在三种方案里都一样确定。

分支图标**带不带文字**用户没回答，实现按纯图标做（复制按钮右侧，同 `.turn-copy` 尺寸），真窗口截图
`shots/03-chat-fork.png` 可以直接看效果；要加文字是 `transcript.ts` 里给按钮多一个 `span` 的事。

原型场景用的是一个**新手势**形状（两条走法各以一条 user 提问起步）。用户真实那条会话是**旧手势**（从
user 消息分叉，走法以助手回答起步），它没有自己的提问；03 的实现在这种形状上借分叉点的 prompt，和根卡
重复时回退到回答预览。真窗口里的样子见 `shots/03-branch.png`。
