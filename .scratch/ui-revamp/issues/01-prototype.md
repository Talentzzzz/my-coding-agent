## Question

六项改动的最终形态是什么？做一份可交互 HTML 原型（`.scratch/ui-revamp/prototype.html`）给用户过目，防止理解偏差：

1. **模型管理**（图1）：去掉右下角全局「保存模型」；「＋ 添加模型」点击后内联展开表单，右下角「取消 / 保存」；已有模型行右侧悬停出现回收站删除；点行中间进入编辑，同样右下角「取消 / 保存」。
2. **模式**：全局设置新增「模式」——用户可创建模式，模式里配置工具集合 + 审批；输入框左下角改为模式下拉，选模式即选工具集与权限集；模式只能在全局设置改，会话只用。
3. **空状态与侧栏**（图2）：去掉中间那段说明文字留白；「新建会话」→「新会话」。
4. **思考块**（图3）：改成与 bash 工具块一致的样式；去掉左边小灯泡；折叠态一行内文字不断滚动。
5. **user 消息**（图4/图6）：分隔线离消息太近、内容太少 → 改为气泡下方右侧「时间 + 复制」，并留足呼吸空隙。
6. **agent 脚注**（图5）：只留 复制 / 用量 / 时间，新增「总用时」；agent 工作中显示计时器。

## Answer

原型经四轮反馈后定稿，用户确认（「就这样」）。最终形态：

1. **模型管理**：无全局保存按钮；「＋ 添加模型」内联展开空表单（取消/保存）；行悬停出现回收站（一次确认后删除）；点行中间进入编辑（取消/保存）。
2. **模式**：全局设置维护模式（名称 + 工具开关 + 每工具审批，**审批默认「自动允许」**，内置默认模式不可删）；输入框左下角为模式下拉，选模式即选工具集与权限集，会话只读。
3. **空状态**：只留图标 + 「想做点什么?」；侧栏按钮「新会话」。
4. **工具/思考条目**：扁平单行、无胶囊容器、无图标、保持工具原名（bash 等）；整行等宽字体、字号更小、颜色分层（名称 500 次级色，摘要 caption 色）；点击展开全文；思考滚动只在流式输出期间，结束后定格第一句。
5. **user 消息**：气泡下右侧「时间 + 复制图标」，与后续内容留足空隙（替代原分隔线）。
6. **agent 脚注**：复制仅图标、无分割线，后接 用量 / 时间 / 用时；运行中为一行纯文字「用时 mm:ss」递增（无胶囊、无「工作中」字样）。

实现细节以原型文件为准：`.scratch/ui-revamp/prototype.html`。
