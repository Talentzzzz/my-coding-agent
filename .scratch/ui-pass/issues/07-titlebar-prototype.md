# 07 标题栏布局原型

Type: prototype
Status: open
Label: feature

## Question

图2 暴露两个标题栏问题，用户要求先做原型再定：

1. 右上角窗口控制按钮（最小化/最大化/关闭）压住了分支页工具行（100% / 适应 / 回到对话）——分支工具行在标题栏正下方，与窗口按钮同高冲突。
2. 标题栏整体太贴屏幕边界。

做法：产出一个便宜的 HTML 原型（放 `prototype/`），给出 2-3 个布局方案（例如：工具行左移避开窗口按钮、标题栏加内边距、窗口按钮区留白列等），交给用户挑。原型确认后从 map 的 Not yet specified 毕业出实现 ticket。
