# 003 立 ADR-0024，并把六份旧 ADR 收账

## Question

怎么把这次转向写下来，让 0008→0012→0013→0014→0022→0023 这条五次搬家的链仍然读得通；用户要求
「按这次的，保持简洁」。

## A. `docs/adr/0024-loop-is-orchestration.md`（目标 110–130 行，不写成长文）

骨架沿用仓库既有 ADR，但每一节只留能改变判断的句子：

```
# 0024：loop 就是编排——删掉 LoopManager，一次运行回到 Agent

日期：2026-11-13 · 状态：已接受（…）
取代：0023 的全部决定 + 0022 的残余（文件分区、零字段对象、单袋形状、静态守卫）；
      亦终止 0008/0012/0013/0014 这条「引擎住哪」的往返
取代者：无

## 背景 / ## 判据：一句话 / ## 决定（6 条） / ## 后果
## 尚未决定 / ## 不可逆性与代价 / ## 被取代的是什么 / 没有被取代的
```

**判据（全文核心，只此一句）**：loop 不是编排**旁边**的一层，它就是编排。0022/0023 划的不是两层的
边界，是同一层内部的边界；既然两边是同一件事，任何为跨越它而付的成本都买不到东西。

**必须正面回答的三问**——0023 的判据是成立的，ADR 不能说它错：

1. **「零 Manager 可见性」成立吗？** 成立，落地也做到了——但它是**内部**可见性，不是跨层的。一条
   边界划在 `Agent` 与 `Agent` 的引擎之间，守的是自己。
2. **0023 买到了什么真东西？** 两件：把 loop 需要什么收成一份 19 项清单（类型上看得见），以及一条
   可机器化的守卫。第一件随方法迁回变成私有的类面，清单本身消失；第二件是**净损失**，如实写进
   「后果」，不要假装没丢。
3. **0008 的试金石现在指向哪？** 它问「为什么这个必须绕回编排层」。边界撤掉后，这个问题不再有
   对象——不是被回答，是被取消。必须写明，否则读者会以为试金石被违反了。

**决定（6 条，每条一句）**：

1. 删 `loop-manager.ts`；14 个成员成为 `Agent` 的私有方法（名单见票 001 §A）。
2. 文件级机件搬到 `agent.ts` 末尾；恢复机器仍导出，`index.ts` 改指 `./agent.ts`（票 002）。
3. `LoopOptions` / `CompactOptions` / `CompactCallbacks` / 七个接缝类型删除；留下的三件值叫
   `RunInput`，它没有依赖面（票 001 §E、票 002）。
4. 19 动词作为**边界契约**死掉：8 个留成私有方法（有逻辑或 ≥3 处复用），其余直调（票 001 §C）。
5. `check-loop-boundary.ts` 删除、`npm run check` 摘一条。守卫不是被削弱，是**没有对象可查**。
6. **不再用搬文件治规模。** 下次嫌 `agent.ts` 大，另开一张图，口径是「一个类一件事」；拆类会立刻
   退回运行对象，那必须是另一场辩论。

**后果（两头都写）**：

- 换来：约 170 行契约文本消失（25 字段接口 + 两条 Pick 链 + 七个接缝类型；其中一部分注释搬到
  了新方法上，所以文件行数不按这个数掉）+ 守卫 + 一个文件；读「一次运行怎么开始」不用在两个文件
  之间跳；运行的读数与命令面的读数成为同一批调用，漂移不可能。
- 背上：`agent.ts` **2820 行**（实测，票 001 §F）、`Agent` 类约 2450 行——0008 那句「没有第二个
  文件可以指」原样回来；**边界审计的机器可见性丢了**，这是这次唯一的净损失，不粉饰。

**尚未决定**：`Agent` 是否该按「命令面 / 一次运行」拆成两个协作对象。明确写出：不在本图内，且拆它
会重新引入一个「运行对象」——那正是 0012，所以需要独立论证，不能顺手做。
